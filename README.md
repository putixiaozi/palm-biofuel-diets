# Vegetable-oil allocation between food and fuel

Code for *Palm restrictions and production geography determine whether biofuel expansion competes with dietary vegetable oils* (Lili Xu, Saisai Guo, Gaojian Ji).

The model allocates 12 vegetable oils between food use and biofuel feedstock in 181 regions for 2010–2023 and for a 2035 projection. It is a set of linear programmes solved with HiGHS through SciPy. This repository contains code only; input data are obtained from their providers as described below, and all results are generated by the scripts.

## Code

| Scripts | Purpose |
|---|---|
| `code/01_extract_fabio.R`, `02_extract_fbs.py`, `03_build_base.py` | Extract and harmonize the input data |
| `code/model.py` | Allocation model |
| `code/04_history.py` … `code/25_allocation_rules.py` | Experiments, decompositions and summary tables |
| `code/fig0.py` … `code/fig5.py`, `figS.py`, `figS14.py` | Figures |
| `code/paths.py` | Repository paths; `FABIO_DIR` points to the FABIO data |

Figure scripts and paper numbering: `fig0.py`–`fig5.py` produce Figs. 1–6. `figS.py` produces Supplementary Figs. 1–7 (`FigS1`–`FigS7`), 8 (`FigS13`), 9–11 (`FigS8`–`FigS10`) and 13–14 (`FigS11`–`FigS12`); `figS14.py` produces Supplementary Fig. 12.

## Input data

Place the inputs in the folders below (relative to the repository root).

| Folder | Data | Source |
|---|---|---|
| `data_fabio/` (or `FABIO_DIR`) | FABIO version 2 supply–use and input–output tables, label files and `regions.csv` | FABIO developers (https://github.com/fineprint-global/fabio); version 2 is shared under a data-use agreement and is not redistributed here |
| `data_raw/usda_psd/` | `psd_oilseeds.csv` | USDA FAS PSD Online, oilseeds bulk file: https://apps.fas.usda.gov/psdonline/downloads/psd_oilseeds_csv.zip |
| `data_raw/oecd_fao/` | `oecd_fao_outlook_2026_2035_oilcomplex.csv` | OECD–FAO Agricultural Outlook 2026–2035 (OECD Data Explorer, dataflow `OECD.TAD.ATM:DSD_AGR@DF_OUTLOOK_2026_2035`; soybeans, other oilseeds, vegetable oils, protein meals, biodiesel and ethanol; all areas and measures, 1990–2035) |
| `data_raw/faostat/` | `FoodBalanceSheets_E_All_Data_NOFLAG.csv` | FAOSTAT Food Balances (2010–) bulk download |
| `data_raw/revision_sources/` | `EIA_feedstocks_monthly.xls`; USDA FAS GAIN Biofuels Annual reports for the EU, Indonesia and Brazil (2024) as text | U.S. Energy Information Administration; USDA FAS GAIN |

## Running

```bash
pip install -r requirements.txt
./run_all.sh
```

`run_all.sh` extracts the inputs, runs all experiments into `results/` and draws the figures into `figures/`. The full run takes several hours on a desktop computer. Tested with Python 3.11 (numpy 2.4, pandas 3.0, scipy 1.16, matplotlib 3.10, geopandas 1.1) and R 4.5. Supplementary Fig. 12 additionally needs a world map layer that is not included.
